# 🚦 Urban Traffic Intelligence — Power BI Dashboard

## 📌 Project Overview
Urban Traffic Intelligence is a data analytics project developed using Microsoft Power BI to explore urban traffic patterns and present key findings through an interactive dashboard.

## 🎯 Project Objectives
- Monitor total vehicle volume.
- Analyze average vehicle speed.
- Evaluate traffic congestion levels.
- Track average travel time.
- Explore accident patterns.
- Identify traffic trends and areas requiring attention.

## 🛠️ Tools & Skills
- Microsoft Power BI
- Power Query
- DAX Measures
- Data Cleaning and Transformation
- Data Visualization
- Interactive Dashboards and Slicers

## 📊 Key Performance Indicators (KPIs)
- Total Vehicles
- Average Speed
- Average Congestion
- Average Travel Time
- Total Accidents

## 📁 Project Files
- `Urban_Traffic_Intelligence.pbix` — Power BI report.
- `Urban_Traffic_Intelligence.csv` — source dataset.
- `dashboard-preview.png` — dashboard screenshot.

## 🚀 How to Explore
1. Download the Power BI report and source dataset.
2. Open the `.pbix` file in Microsoft Power BI Desktop.
3. Review the KPI cards, charts, and filters.
4. Explore traffic patterns and compare categories and time periods.
